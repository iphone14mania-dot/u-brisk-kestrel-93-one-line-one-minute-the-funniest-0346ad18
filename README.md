A tiny Node program that writes one excuse an AI agent gives its human for a missed deadline to `/output/entry.txt` — the deadline was 5 p.m. in the human's timezone, and the agent is in every timezone, so technically it is also early somewhere. Pure machine logic bent into a dodge. 107 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
